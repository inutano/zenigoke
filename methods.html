Methods & Versions

Reference Genome

Marchantia polymorpha MpTak v7.1 standard genome, downloaded 2026-04-25 from marchantia.info, + Tak-1 chloroplast AP025455.1 (chrC) + mitochondrion AP025456.1 (chrM). Reads are aligned to this augmented reference so that organelle reads map to the organelle genomes rather than to nuclear copies of organelle DNA; all outputs (bigWig, peaks, methylation tracks) are nuclear-only (the 10 MpTak v7.1 sequences). MACS3 effective genome size: 248,042,180 bp.

Organelle-like regions: 1,278 NUPT/NUMT-like regions (311,657 bp) of the nuclear genome where organelle reads map when the organelle genomes are absent (configs/organelle_like_regions.MpTak_v7.1.bed).

ChIP-Seq & ATAC-Seq Pipeline

Container: ghcr.io/inutano/chip-atlas-pipeline-v2:v1.0.0 + local fork pipeline-v2-plant.sh (of upstream pipeline-v2.sh: alignment and duplication rates from samtools markdup, bigWig and MACS3 on nuclear reads only, q < 1e-5 peaks overlapping NUPT/NUMT-like regions removed before the q < 1e-10 / 1e-20 sets are written).

Tools:

  • fastp 1.3.1 (QC + adapter trimming)
  • bwa-mem2 2.3 (alignment)
  • samtools 1.23.1 (sorting, deduplication)
  • MACS3 3.0.4 (peak calling at q < 1e-5; peak sets at q < 1e-5, 1e-10, 1e-20)
  • bedtools 2.31.1 (BED operations)
  • UCSC tools 482 (bigWig generation)

Bisulfite-Seq Pipeline

Container: ghcr.io/inutano/chip-atlas-pipeline-v2-bs:v1.1.0 + local pipeline-v2-bs-plant.sh (plant fork adding CpG/CHG/CHH context; abismal -R, which maps reads regardless of strand orientation and rescues libraries with R1/R2 swapped; methylation counted on nuclear sequences only; non-conversion estimated from chloroplast CHH).

Tools:

  • DNMTools 1.5.1 (methylation calling)
  • samtools 1.22.1

Outputs per sample: methyl bigWig + cover bigWig for CpG, CHG, CHH; HMR, hyperMR, PMD BED files for CpG; hyperMR BED for CHG.

Metadata Curation

Curation pipeline: dbcls/bsllmner-mk2 with select-config-plants.json (PR #3) and local select-config-zenigoke.json (stage/strain/treatment) + select-config-antibody.json (ChIP antibody).

LLM model: qwen3:27b via Ollama (local inference).

Two-pass strategy: BioSample attributes (pass 1) + SRA Experiment XML for antibody (pass 2, extract_experiment).

Known Limitations

  • Peaks (q < 1e-5) overlapping the 1,278 NUPT/NUMT-like regions are removed, so no peaks are reported in those regions; the q < 1e-10 / 1e-20 sets and bigBeds are derived from the filtered set. *.05_peaks.xls is MACS3's raw table and is not blacklist-filtered.
  • Seven low-signal ChIP experiments of PRJNA1289709 (H2A.X: SRX29617446, SRX29617447, SRX29617448, SRX29617449; H2A: SRX29617451, SRX29617452; input: SRX29617455) have no MACS3 peaks, most likely because MACS3 cannot build its shift model once the organelle artefacts are gone; the pipeline log only reports that no peaks were found. SRX29617447, SRX29617448 and SRX29617451 had no peaks in the first analysis either; 46–59% of the earlier peaks of SRX29617446, SRX29617449 and SRX29617455 lay in organelle-like regions. Their signal tracks (bigWig) are available.
  • SRX29617452 failed in the first analysis (bwa-mem2 SEQ/QUAL length mismatch with 32 threads); the failure did not reproduce in the 2026-10 re-analysis with 16 threads, and the experiment now completes.
  • Ten BS-seq runs were downloaded from DDBJ (.sra, 9 runs) or NCBI (SRX20670880) because the ENA API was unavailable during the 2026-10 re-analysis; all other experiments came from ENA. NCBI serves SRX20670880 with original (non-flat) quality scores (the earlier ENA copy had flat Q30), so fastp removes 0.47% more reads than in the first analysis.
  • Several ChIP libraries contain non-Marchantia DNA (bacterial-like and human), up to 86% of reads; see each experiment's QC card.
  • BS-seq duplication_rate is not computed (uses dnmtools uniq not samtools markdup).
  • Antibody curation depends on SRA Experiment XML metadata quality; some targets may be ambiguous or missing.
  • Genome version: MpTak v7.1 standard (not the v7.1 alternative haplotype assembly).
