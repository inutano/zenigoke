IGV isn't responding?
  1. Start IGV desktop (2.19 or later). The port is on by default; if it was turned off: View › Preferences › Advanced › Enable port 60151.
  2. Chrome, Edge (142+) and Firefox ask once to let this site access other apps and services on this device. Choose Allow. If you blocked it, re-allow it in the site settings.
  3. Safari blocks pages from calling localhost. Use Send via link, or download the session file and open it in IGV with File › Open Session…
