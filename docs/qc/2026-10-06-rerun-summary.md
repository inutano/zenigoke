## アライメント率

QC 調査の予測値は、ChIP/ATAC では `nuclear_aug_pct + organelle_pct`、BS-seq では `sub_R_plus_organelle` とした。どちらもオルガネラ入り参照で測ったサブサンプルの値である。v2 の実測値は 157 実験中 156 実験でこの予測の ±5 pt 以内に収まった。差の中央値は +0.06 pt である。ChIP/ATAC では、旧参照で測った `aligned_pct` を 2 pt 以上下回る実験は SRX22603363 だけだった。

- **SRX22603363**（ChIP、GLK）は v2 が 87.8%、予測が 96.75% で、9 pt 下回った。重複除去後に残ったリード数は v1 と v2 でほぼ同じ（10.48M と 10.45M）なので、データ自体は変わっていない。予測に使った先頭 100k スポットのサブサンプルが楽観的だったと考える。なお、ENA が配る FASTQ の中身が 4 月から 10 月までの間に変わっている。v1 の取得分は品質値がすべて Q30 で、v2 の取得分は元の品質値を持つ（FASTQ は 1.20 GB から 1.70 GB に増えた）。このため fastp で落ちるリード数が 726 から 89,732 に増えた。対応は不要と判断した。
- **SRX2613730**（BS、DDBJ）は予測より 3.2 pt 低い。v1 の ENA コピーは品質値が 2 値化されていた（q20 率と q30 率がともに 0.956）。DDBJ の `.sra` は元の品質値を持ち、fastp を通るリードが 5.0% 多い（80.1M から 84.1M）。増えた分は品質の低いリードなので、アライメント率がやや下がった。5 pt 以内なので、それ以上は調べていない。

## 重複率

QC の TSV の `dup_pct` は推定値で、`1 − M / (R × (a + s))` から求めている。M は重複除去後のレコード数、R は fastp 通過リード数、a と s はサブサンプルのアライメント率と supplementary の比率である。v2 の重複率は `samtools markdup` の `DUPLICATE PRIMARY TOTAL / EXAMINED` で、primary アライメントについての実測値になる。差の中央値は +0.9 pt である。5 pt を超えて上がったのは次の 2 群である。

- PRJNA1289709 の input（SRX29617453、454）は +12〜13 pt、オルガネラ由来のリードが 12% ある SRX29617449 は +5.1 pt 上がった。オルガネラ由来のリードが整列するようになり、その重複が数に入ったためである。
- PRJNA1289709 のヒト DNA が混入した試料（SRX29617456、457、464、465、470、471、478、479）は +8〜14 pt 上がった。推定式の supplementary 補正がずれていたためで、重複除去後のリード数は v1 と変わらない。

## オルガネラ

- ChIP/ATAC の QC 判定は、引き続き TSV の `organelle_pct`（fastp 通過リードに占める割合。20% の閾値はこの基準で決めた）を使う。v2 の値（重複除去後のレコードに占める核以外の割合）は別の行として表示する。
- 重複の多い ATAC では、v2 の割合が TSV より小さい（例：SRX27755071 は 50.0% と 14.0%）。オルガネラ由来のリードが重複除去で大きく減るためである。アライメント率の低い ChIP では逆に v2 の割合が大きい（例：SRX9800298 は 0.73% と 4.63%）。分母が整列したリードだけになるためである。
- 「organelle reads」の WARN は差し替えの前後とも 24 件で、減っていない。

## ピーク

- ピークが出た 119 実験で、q < 1e-5 のピーク 1,896,468 件のうち 22,807 件（1.2%）がオルガネラ様領域に重なり、除かれた。除かれた割合が大きいのは SRX29617453（1,298 件中 762 件）、SRX29617454（1,257 件中 742 件）、SRX29617482（347 件中 110 件）である。
- v1 に対する v2 の q < 1e-5 ピーク数の比は、ChIP で中央値 0.965、ATAC で 0.968（範囲 0.897〜0.985）だった。大きく減ったのは、旧ピークの多くがオルガネラ様領域にあった実験である。PRJNA1289709 の input 6 実験は比 0.19〜0.30（SRX29617453 は 2,740 から 536、454 は 2,665 から 515）、PRJNA641427 の 10 実験は比 0.33〜0.76 だった。
- PRJNA1289709 の 7 実験は、v2 で q < 1e-5 のピークが 0 件になった。H2A.X の SRX29617446、447、448、449、H2A の SRX29617451、452、input の SRX29617455 である。ログには MACS3 のモデル推定の失敗（`No peaks found (MACS3 model building may have failed …)`）が残っている。このうち 447、448、451 は v1 でも 0 件、452 は v1 で失敗していた。446、449、455 は、v1 のピークの 46〜59% が 1,278 領域に重なっていた。NUPT 上の積み上がりが消えたため、MACS3 がモデルを作れなくなったと考える。残る真のピークを取りこぼしている可能性がある。`--nomodel` で呼び直すかどうかは所有者が判断する（パイプラインの変更と、この 7 実験の再実行が要る）。bigWig は 7 実験とも出ている。
- `*.05_peaks.xls` は MACS3 の生の表で、除外リストによる絞り込みはかかっていない。

## BS-seq

- SRX2613745 と SRX2613731（R1/R2 が入れ替わっていた 2 件）は、`abismal -R` によって平均メチル化率が全コンテキスト約 0.99 から正常な値に戻った。CpG/CHG/CHH の値は 745 が 0.311/0.162/0.052、731 が 0.450/0.318/0.092 である。CpG の 5× 以上の割合も 745 で 0.2% から 1.6%、731 で 1.4% から 5.5% に上がった。

## QC 判定の変化

差し替えの前後で、v1 の DB も同じコードで作り直して比べた。

| | FAIL | WARN | PASS |
|---|---|---|---|
| 差し替え前（v1） | 18 | 72 | 67 |
| 差し替え後（v2） | 15 | 72 | 70 |

判定が変わったのは 5 件である。

- SRX29617452（ChIP）は FAIL から PASS になった。パイプラインが完走したためである。
- SRX2613745（BS）は FAIL から WARN になった。全コンテキストの高メチル化が解消し、非変換率は 2.07% から 1.93% に下がった。CpG の 5× 以上が 1.6% なので WARN が残る。
- SRX2613731（BS）は FAIL から WARN になった。高メチル化が解消し、CpG の 5× 以上が 5.5% になった。非変換率 2.4% で WARN が残る。
- SRX22603363（ChIP）は WARN から PASS になった。重複率が推定値 51.5% から実測値 46.6% に下がった。
- SRX2613739（BS）は WARN から PASS になった。非変換率が TSV の 2.2% からパイプラインの 1.88% に下がった。

判定は変わらずに理由だけが変わったものもある。

- ピークの判定（`peak_flag`）の WARN は 31 件から 0 件になった。v2 のピークは除外リストで絞り込み済みなので、オルガネラ様領域の割合はもう測らない。ページには「removed by blacklist」と出る。NA は 4 件から 7 件になった（ピーク 0 件の 7 実験）。
- SRX27755072（ATAC）は、重複率が 49.5% から 52.5% になり、WARN の理由が 1 つ増えた。
- SRX22603366、SRX29617470 は、「使える断片数 < 4M」の理由が加わった。v2 は核のリードだけを数えるためである（SRX22603366 は 3.4M、SRX29617470 は 3.99M）。
