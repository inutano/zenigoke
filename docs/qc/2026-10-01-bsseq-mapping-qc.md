# BS-seq（WGBS）サンプルのマッピング率低下に関する QC 調査

調査日：2026-10-01

対象：カタログ収録の Bisulfite-Seq 31 実験（PRJNA378146 24 件、PRJDB8102 4 件、PRJNA983345 2 件、PRJNA286703 1 件）

サンプル別の判定表：`docs/qc/2026-10-01-bsseq-qc.tsv`

検証用の作業ディレクトリ：`/data1/zenigoke/tmp/qc-20261001-bs/`（サブサンプル FASTQ、検証用インデックス、集計スクリプト一式）

本調査ではパイプライン、DB、レポート、既存出力のいずれも変更していない。
修正案はすべて差分またはコマンドとして本書に記載した。

## 要旨

表示されているマッピング率の低さは、四つの別々の要因が重なった結果である。
件数の多い順に並べると次のとおり。

| 順位 | 原因 | 該当件数 | 表示値への影響 | 確度 |
|---|---|---|---|---|
| 1 | 参照配列（MpTak_v7.1）に葉緑体とミトコンドリアのゲノムが含まれていない | 26 / 31 | 表示値を 9.8〜36.3 ポイント押し下げる。リードの 13〜53% が葉緑体由来 | 検証済み |
| 2 | PE の表示値が「一致ペア率」であり、リード単位の率より低く出る（指標の定義） | 25 / 27（PE のうち R1/R2 が逆の 2 件以外） | リード単位の率より 4〜12 ポイント低い | 検証済み |
| 3 | SRA 上の R1/R2 の取り違え（directional ライブラリを逆向きに登録） | 2（SRX2613745、SRX2613731） | 10〜13% に低下。メチル化率（全コンテキスト 0.98〜0.99）は誤り | 検証済み |
| 4 | 細菌 DNA の大量混入（GC リッチで CpG 非メチル化、Rhodanobacteraceae 近縁） | 2（DRX162963、DRX162964） | リードの 81〜85% が核にもオルガネラにも配置されない（同じ研究の変異体では 13%） | 混入の存在は検証済み、菌種は推定 |

当初の仮説のうち、PBAT や non-directional ライブラリを directional モードでマップしたという説明は、DRA のデータ（DRX1629xx）を含めて当てはまらなかった。
4 件の DRX はいずれも R1 の C 含量が 0.4% の directional ライブラリであり、`-P`（PBAT）モードでは率が 1.4〜15.4% に下がる。

要因 1 には、マッピング率とは別の副作用がある。
葉緑体とミトコンドリアのリードの一部が核ゲノム上の葉緑体様挿入配列（NUPT、NUMT）に誤って配置され、現行の出力に非メチル化の高カバレッジ領域を作っている。
葉緑体の多いサンプルでは、核ゲノムの 0.85% にあたる領域が CpG カバレッジの 7〜12% を占め、そこでのメチル化率はほぼ 0 になる。
この点は 3.1 節の後半で示す。

マッピング率の調査の過程で、変換効率の問題も一つ見つかった。
葉緑体上の見かけのメチル化率から求めた非変換率は、SRX2613726（Late Sporophyte SPHo_7）で 9.2% あり、全コンテキストのメチル化率が水増しされている（非 CG で影響が相対的に大きい）。
これはマッピング率の低さとは関係がない（表示値 70.7%）。

本当に問題のあるサンプル（表示中のメチル化値が誤っている、または情報量が極端に少ない）は次の 5 件である。

- **SRX2613745**（Thallus TH_9）と **SRX2613731**（Archegonium Arch_13）：R1/R2 が逆。メチル化値が無効なので再解析が必須。
- **SRX2613726**（Late Sporophyte SPHo_7）：非変換率 9.2%。メチル化率が CpG で約 6 ポイント、CHG で約 7 ポイント、CHH で約 8 ポイント過大になっている。
- **DRX162964** と **DRX162963**（Ikeda ら、WT）：細菌混入。マップされた部分のメチル化値は妥当だが、有効深度が低い（CpG のカバー率 30% と 43%）。

## 1. 表示されている mapping_rate の意味

### 値の出どころ

カタログの `sample.mapping_rate` は、パイプラインが書き出す stats TSV の 6 列目をそのまま格納したものである。
`scripts/pipeline-v2-bs-plant.sh` はこの値を abismal の統計ファイル（YAML）の最初の `percent_mapped:` 行から取得する。

```bash
# scripts/pipeline-v2-bs-plant.sh（現行）
if [ "$IS_PAIRED" = true ]; then
  READ_COUNT=$(grep "total_pairs:" "$WORK/abismal.stats" | head -1 | awk '{print $2}')
else
  READ_COUNT=$(grep "total_reads:" "$WORK/abismal.stats" | head -1 | awk '{print $2}')
fi
MAP_RATE=$(grep "percent_mapped:" "$WORK/abismal.stats" | head -1 | awk '{print $2}')
```

`scripts/build_catalog_db.py` の `parse_bsseq_stats()` は、5 列目を `reads_filtered`、6 列目を `mapping_rate`、2 列目を `layout` に入れる。
`layout` の `0` は SE、`1` は PE である（パイプラインの `LAYOUT_FLAG` と `build_catalog_pages.py` の `_layout_label()` で確認）。
BS-seq の `reads_mapped` と `duplication_rate` が NULL なのは、stats TSV にその列がないためである。

### abismal（dnmtools 1.5 系、abismal v3.3.0）の統計の定義

SE では、`percent_mapped` は fastp 通過後のリードのうち、ゲノムに配置されたリード（一意 + 多重）の割合である。

PE では、YAML の最初の `percent_mapped` は `pairs:` セクションに属する。
これは fastp 通過後のペアのうち、**一致ペア**（concordant pair、向きと断片長 32〜3000 bp の条件を満たすペア）として配置されたペア（一意 + 多重）の割合である。
片側の mate だけが配置された場合はペアとして数えない。
`mate1:` と `mate2:` のセクションは、一致ペアにならなかったペアと多重ヒットのペアの各 mate を SE として再マップした結果である。

この解釈は、サブサンプルの BAM で確かめた。
SRX2613744 の 249,696 ペアでは、`mate1.total_reads`（114,317）が `pairs.num_unmapped` と `pairs.num_ambiguous` の和に一致した。
BAM のレコード数 220,978 は「一意な一致ペア × 2 + SE として一意に配置された mate」の値と完全に一致した。

この定義から、表示値について次の 3 点が言える。

- 多重ヒット（ambiguous）が分子に含まれる。多重ヒットのリードは BAM に出力されず、メチル化の計算には使われない。たとえば SRX2613734 は表示 92.1% だが、一意な一致ペアは 73.1% である。
- PE の表示値はリード単位の率より低い。片側だけ配置された mate も数えたリード単位の率は、R1/R2 が逆の 2 件を除く PE 25 件で表示値より 3.8〜12.0 ポイント高い（例：SRX1060228 は表示 78.6%、リード単位 83.1%）。
- SE（DRX 4 件）と PE の値は直接比較できない。

## 2. 調査の方法

全 31 実験について、ENA から各ランの先頭 25 万リード（PE は 25 万ペア）だけを取得した。
フルランは取得していない。

```bash
# 例：ENA filereport から URL を得て先頭 100 万行だけを保存
curl -s "https://$URL" | zcat | head -n 1000000 | gzip > fq/${ACC}_1.fq.gz
```

サブサンプルには、パイプラインと同じ既定パラメータの fastp を適用した。
マッピングには `run-sample.sh` と同じコンテナ（`ghcr.io/inutano/chip-atlas-pipeline-v2-bs:v1.1.0`、abismal v3.3.0）を使い、スレッド数は 12 以下に抑えた。

比較したモードと参照配列は次のとおり。

- **directional**：現行パイプラインと同じ既定モード。
- **-R**（random PBAT）：各リードを両方の変換向きで試すモード。
- **-P**（PBAT）：R1 が G→A 変換鎖であると仮定するモード。
- **-A**（a-rich、SE のみ）：SE リードが A リッチであると仮定するモード。
- 参照配列は、現行の MpTak_v7.1、これに葉緑体（AP025455.1、Tak-1）とミトコンドリア（MK202951.1）と λ ファージ、phiX、pUC19 を加えたもの、さらに細菌 37 ゲノムを加えた競合マッピング用のもの、の 3 種類を用意した。

サブサンプルの directional モードの率は、フルランの表示値と最大 0.6 ポイントの差で一致した（DRX162964 は 9.2% に対して 9.5%、SRX2613744 は 42.3% に対して 42.4%、SRX2613745 は 10.4% に対して 10.5%）。
したがって、以下のモード比較の数値はフルランにもそのまま当てはまると考えてよい。

塩基組成は、フルランの fastp JSON（`/data1/zenigoke/output/bsseq/*/*_fastp.json`）の位置別組成曲線から、5〜60 塩基目の平均として求めた。

## 3. 原因別の所見

### 3.1 参照配列に葉緑体とミトコンドリアがない

MpTak_v7.1 standard genome の FASTA は chr1〜chr8、chrV、chrU の 10 本だけからなる。
MarpolBase の README には、アセンブリ前に葉緑体とミトコンドリアのリードを除き、それらに由来する短いコンティグも除いたと明記されている。

> Reads mapped to chloroplast and mitochondrion sequences were removed before conducting de novo assembly.
> Short contigs possibly derived from chloroplast, mitochondrion, and rDNA clusters were removed.
> （https://marchantia.info/data/README.md）

葉緑体 DNA は細胞あたりのコピー数が多く、メチル化されていない。
そのため、葉状体のような葉緑体の多い組織の WGBS では、リードの大きな割合が葉緑体由来になる。
参照に葉緑体がなければ、それらのリードはマップされないか、核ゲノムの似た配列に誤って配置される。

葉緑体とミトコンドリアを参照に加えると、マッピング率は次のように上がった（サブサンプル、`-R` モード）。

| グループ（組織） | 件数 | 現行（directional） | +オルガネラ | 葉緑体リード | ミトコンドリアリード |
|---|---|---|---|---|---|
| PRJNA378146 Thallus（TH_2/7/11/13/14） | 5 | 42.4〜56.1% | 60.3〜82.8% | 14〜53% | 1.5〜3.5% |
| PRJNA378146 Apical Notch（AN） | 6 | 49.8〜57.4% | 73.9〜84.3% | 32〜46% | 3.3〜4.8% |
| PRJNA378146 Archegonium（Arch_7/14） | 2 | 56.2〜62.6% | 73.5〜83.8% | 20〜25% | 3.4〜4.3% |
| PRJNA378146 Sporophyte（SPHo、SPHy） | 6 | 58.7〜73.9% | 77.4〜90.7% | 15〜30% | 2.7〜10.4% |
| PRJNA378146 Antheridia Sperm（Anth） | 3 | 87.2〜92.1% | 87.9〜93.2% | 0.6〜1.2% | 0.01% |
| PRJDB8102 Mpmet（DRX162965/66） | 2 | 68.1〜69.8% | 86.6〜87.1% | 25〜27% | 5.1% |
| PRJNA983345 T-WGBS | 2 | 71.6〜72.5% | 86.3〜89.0% | 13% | 3.2〜6.2% |
| PRJNA286703 | 1 | 79.2% | 95.7% | 21% | 3.2% |

精子（Anth）の 3 件だけが葉緑体リードをほとんど含まず、もともと 87〜92% と高い。
同じプロジェクト、同じキット、同じシーケンサーのサンプル間で率が 42% から 92% まで広がっていた理由は、組織あたりの葉緑体 DNA 量の違いでほぼ説明できる。
葉緑体とミトコンドリアを加えたときの上昇幅は、精子 3 件と細菌混入の 2 件を除く 26 件で 9.8〜36.3 ポイントだった。

#### 現行出力への副作用（NUPT と NUMT への誤配置）

参照に葉緑体がないとき、葉緑体リードの一部は核ゲノム上に「マップされた」ものとして数えられる。
同じサブサンプルを現行の参照と葉緑体入りの参照に `-R` でマップし、核染色体上に一意に配置されたリード数を比べた。
現行の参照で核に配置されたリードのうち、葉緑体入りの参照では核から外れた割合は、精子 3 件で 0.3〜0.6%、それ以外の 28 件で 11〜49% だった（SRX2613746 で 49.1%、SRX2613745 で 47.0%）。

これらの誤配置リードは特定の領域（葉緑体様の配列を含む核の領域で、NUPT と考えられる）に集中する。
SRX2613746 では、誤配置リードの 70% が上位 50 個の 10 kb ウィンドウに、90% が 187 個のウィンドウ（計 1.87 Mb、核ゲノムの 0.85%）に集まっていた。
この 187 ウィンドウが現行の出力 bigWig で CpG カバレッジ全体の何割を占めるかを調べると、組織による違いがはっきり出る。

| サンプル | 組織 | 187 ウィンドウが占める CpG カバレッジの割合 | 187 ウィンドウ内の重み付き CpG メチル化率 |
|---|---|---|---|
| SRX2613738 | Apical Notch | 11.5% | 0.017 |
| SRX2613746 | Thallus | 9.9% | 0.022 |
| SRX2613724 | Late Sporophyte | 7.7% | 0.041 |
| SRX2613744 | Thallus | 6.9% | 0.021 |
| SRX1060228 | （PRJNA286703） | 3.6% | 0.036 |
| SRX20670880 | Thallus（T-WGBS） | 2.7% | 0.051 |
| SRX2613734 | Antheridia Sperm | 0.8% | 0.574 |
| SRX2613733 | Antheridia Sperm | 0.7% | 0.612 |

精子ではゲノムに占める割合（0.85%）どおりのカバレッジしかなく、メチル化率も 0.57〜0.61 ある。
葉緑体の多い組織では、同じ領域がカバレッジの 7〜12% を吸い込み、メチル化率はほぼ 0 になる。
個別の領域で見ると、chr5:14,030,000-14,050,000 は SRX2613746 で平均カバレッジ 465（背景の chr1:5-6 Mb は 3.4）、平均メチル化率 0.009 だが、SRX2613734 では平均カバレッジ 31、平均メチル化率 0.448 である。
したがって、これらの領域で葉緑体の多いサンプルが示す値は、核のコピーではなく葉緑体 DNA のメチル化状態（非メチル化）を反映していると考えられる。

なお、この領域の HMR 自体は精子でも呼ばれており（SRX2613734 の `chr5:14001912-14065528`）、HMR の有無だけでは誤配置の影響を判定できない。
187 ウィンドウと重なる HMR の割合も、HMR が 1,000 個以上ある 27 件で 2.3〜4.5% と、精子を含めてほぼ同じだった。
影響が出るのは、領域ごとのメチル化率とカバレッジ、そしてカバレッジで重み付けした全体のメチル化率（stats TSV の 7 列目）である。
たとえば SRX2613746 では CpG カバレッジの約 10% がメチル化率 0.02 の領域に由来するので、重み付きの全体値はその分だけ低く出る。

### 3.2 R1/R2 の取り違え（SRX2613745、SRX2613731）

SRX2613745（TH_9）と SRX2613731（Arch_13）は、同じプロジェクトの他の 22 件と同じ KAPA HTP キットと EpiTect による directional ライブラリである。
しかし fastp の塩基組成では、この 2 件だけ R1 と R2 の性質が逆になっている。

| サンプル | R1 の C | R1 の G | R2 の C | R2 の G |
|---|---|---|---|---|
| SRX2613745 | 0.158 | 0.009 | 0.011 | 0.154 |
| SRX2613731 | 0.176 | 0.054 | 0.052 | 0.178 |
| 同プロジェクトの他の 22 件 | 0.010〜0.094 | 0.140〜0.215 | 0.145〜0.218 | 0.008〜0.087 |

directional ライブラリでは R1 が C→T 変換鎖を読むので C が枯渇し、R2 は G が枯渇する。
この 2 件では R1 が G 枯渇、R2 が C 枯渇であり、R1 のファイルに R2 のリードが入っていると判断した。
abismal の一意ペアの誤り率も 7.8% と、他のサンプル（0.4〜2.1%）より 1 桁高い。

モード比較の結果は次のとおり（サブサンプル、一致ペア率）。

| サンプル | directional（現行） | -P | -R | R1/R2 を入れ替えて directional | -R + オルガネラ |
|---|---|---|---|---|---|
| SRX2613745 | 10.5% | 42.0% | 42.1% | 42.0% | 73.6% |
| SRX2613731 | 12.9% | 47.1% | 47.1% | 47.1% | 69.2% |

`-P`、`-R`、ファイルの入れ替えはいずれも同じ結果になり、誤り率も 2.0% と 1.3% に下がった。
オルガネラを加えると、兄弟サンプルと同程度の 69〜74% になる。

DB のメチル化率（mean_cpg 0.99、mean_chg 0.99、mean_chh 0.99）は誤りである。
逆向きのリードは、亜硫酸水素塩で変換された鎖の相補鎖を写したものである。
リード上の C は変換された鎖の G を写したものなので、メチル化の有無にかかわらず C のまま残る。
directional モードはこのリードの C をメチル化シトシンとみなす向きで配置するので、すべての C が「メチル化」として数えられる。
一方、変換で生じた A は参照の G とのミスマッチになるので、マップできるのは変換された鎖に非メチル化の C が少ない領域に限られる。
`-R` でマップし直して dnmtools format と counts を通すと、SRX2613745 の核ゲノムの値は CpG 0.303、CHG 0.143、CHH 0.048 になり、同じ Thallus の兄弟サンプル（mean_cpg 0.30〜0.34）と整合した。
SRX2613731 も同様に CpG 0.431、CHG 0.283、CHH 0.076 となり、同じ Archegonium の兄弟サンプル（mean_cpg 0.46〜0.52）と整合した。

### 3.3 細菌 DNA の混入（DRX162963、DRX162964）

PRJDB8102（Ikeda ら）の 4 件は、同じ日付のサンプル名を持ち、同じ NextSeq 500 で読まれた SE 約 75 bp のデータである。
野生型の 2 件（DRX162963、DRX162964）だけが 9〜13% で、Mpmet 変異体の 2 件（DRX162965、DRX162966）は 68〜70% だった。

まず、ライブラリの向きの問題ではない。
4 件とも R1 の C 含量は 0.4% で、directional の C→T 変換鎖である。
モード比較でも、directional と `-R` はほぼ同じ値（9.5% と 9.6%、13.6% と 13.6%）で、`-P` と `-A` では 1.4〜2.4% に下がった。

違いは G 含量にある。
R1 の G 含量は、野生型 2 件で 0.29〜0.30、変異体 2 件で 0.175〜0.18 だった。
DRX162964 のサブサンプルでは、マップされなかったリードの G 含量は 30〜35% を中心に分布し、マップされたリード（15〜30% に分布）より高い側にずれている。
未マップのリードでは CpG の C の保持率（CG/(CG+TG)）が 0.7% で、マップされたリード（4.3%）より低い。
変換後の G 含量から元の配列の GC 含量はおよそ 60〜70% と見積もられ、CpG はほぼメチル化されていない。
この組み合わせは、高 GC の細菌ゲノムに典型的である。

細菌の参照ゲノムを使った確認では、菌種までは同定できなかったが、系統はある程度絞り込めた。
未マップリードを 14 ゲノム（13 属）の細菌パネルにマップすると、マップされたのは 3.7%（誤り率 8.3%）にとどまり、最多は Xanthomonas campestris だった。
Xanthomonadales の 9 ゲノムでは 10.7% がマップされて Rhodanobacter denitrificans が最多になり、Rhodanobacteraceae の 15 ゲノムでは計 19.5% が誤り率 6.2% でマップされた（特定の 1 種への集中はない）。
50 属の 16S rRNA 基準配列では、細菌に一意にマップされた 73 リードのうち 47 リードが Rhodanobacteraceae（Frateuria、Rhodanobacter、Fulvimonas、Dyella など）、10 リードが Burkholderia だった。
混入源は Rhodanobacteraceae に属する、手元のパネルにない土壌細菌である可能性が高い。

葉緑体、ミトコンドリア、λ、phiX、pUC19 を加えても率は 1〜2 ポイントしか上がらない（9.5% → 10.3%、13.6% → 15.5%）。
変異体の 2 件では細菌パネルへのマップは 0.1% 未満だった。
混入は野生型の 2 件に固有である。

マップされたリードは Marchantia 由来であり、メチル化値そのものは使える。
細菌パネルを加えた競合マッピングでも、核に配置されるリードはほとんど変わらなかった（細菌側に移ったのは DRX162963 で 2.9%、DRX162964 で 4.9%）。
移った分は CpG が非メチル化なので、現行の値はメチル化率を相対的に数% 低く見積もっている可能性がある。
問題は有効深度で、CpG のカバー率は DRX162963 で 43%、DRX162964 で 30%、5 リード以上のカバーは 1.4% と 0.2% にとどまる。

### 3.4 当てはまらなかった仮説

**PBAT、non-directional、random priming**：R1/R2 が逆の 2 件を除く 29 件で、`-R` と directional の差は最大 0.3 ポイントだった。
non-directional ライブラリなら CTOT/CTOB 由来のリードが `-R` で新たにマップされるので、この差は大きくなるはずである。
R1 の C 含量（0.4〜9.4%）と G 含量からも、29 件すべてが directional と判断できる。

**アダプター、ランダムプライマー、Accel-NGS のテール**：fastp の自動検出でアダプターは除去されている。
SRX2613744 と SRX2613747 の未マップのペアのうち、Illumina アダプター配列（AGATCGGAAGAGC）を含むものは 0.1% だった。
Swift Accel-NGS を使ったデータは含まれていない。
T-WGBS（PRJNA983345）の末端の偏り（M-bias）は今回評価していない。

**PE の扱い（retry-pe-fallback による分割、PE の SE 扱い）**：BS-seq の 31 実験はすべて 1 実験 1 ランで、PE の 27 件は ENA に `_1` と `_2` のファイルがある。
ログでも全件 `fwd` と `rev` の 2 ファイルで実行されており、`retry-pe-fallback.sh` は使われていない。
SE の 4 件は ENA 上も SINGLE である。

**性染色体**：参照は chrV（Tak-1、雄）と chrU（Tak-2、雌）の両方を含むので、性別の不一致はマッピング率に影響しない。
常染色体に対するカバレッジ比から推定した性別は TSV の `sex_inferred` 列に入れた。
メタデータで「Tak1/Tak2」や「wild type」となっているサンプルの多くは、実際には雄か雌のどちらか一方だった（Apical Notch では AN_14 と AN_13 が雌、AN_11、AN_9、AN_2 が雄、AN_7 は両方）。
これはキュレーションの補正に使える。

**スパイクイン**：phiX は PRJNA378146 でリードの 0.17〜0.41%、λ は SRX1060228 で 0.1% だった。
pUC19 はどのサンプルでもほぼ 0 だった。
いずれもマッピング率への影響は小さい。

**変換不良によるマッピング率の低下**：リード上の非変換の C は参照の C と一致するので、変換不良はマッピング率を下げない。
実際、非変換率 9.2% の SRX2613726 も表示値は 70.7% で、兄弟サンプル（58.6% と 71.6%）と同程度だった。
変換効率そのものには 1 件問題があったので、次の節で扱う。

### 3.5 変換効率（マッピング率とは別の所見）

葉緑体 DNA はメチル化されていないので、葉緑体上の見かけのメチル化率は、そのサンプルの非変換率の推定値になる。
2 節で述べた競合マッピング用の参照（核 + 葉緑体 + ミトコンドリア + スパイクイン + 細菌 37 ゲノム）に `-R` でマップした BAM を dnmtools format と counts に通し、葉緑体上の CHH の重み付きメチル化率を求めた。
λ を含む SRX1060228 では、λ 上の値（0.38%）と葉緑体上の値（0.27%）がよく一致し、この推定法の妥当性を裏づけている。

31 件の非変換率の分布は次のとおり。

| 非変換率（葉緑体 CHH） | 件数 | サンプル |
|---|---|---|
| 1% 未満 | 10 | SRX1060228、SRX2613736〜38、SRX2613740、SRX2613744、SRX2613746、DRX162963、DRX162964、DRX162966 |
| 1〜2% | 11 | SRX20670880、SRX20670881、DRX162965、SRX2613724、SRX2613725、SRX2613728、SRX2613734、SRX2613735、SRX2613741、SRX2613743、SRX2613747 |
| 2〜5% | 9 | SRX2613727（2.8%）、SRX2613729（3.0%）、SRX2613730（2.5%）、SRX2613731（2.4%）、SRX2613732（2.6%）、SRX2613733（2.3%）、SRX2613739（2.2%）、SRX2613742（2.2%）、SRX2613745（2.1%） |
| 5% 以上 | 1 | SRX2613726（9.2%） |

SRX2613726 では、葉緑体（CpG 8.7%、CHG 9.3%、CHH 9.2%）とミトコンドリア（9.4〜9.5%）が同じ値を示した。
非メチル化であるはずの 2 種類のゲノムが揃って 9% 前後を示すことから、変換不良と判断した。
同じ Late Sporophyte の 2 件（SRX2613724、SRX2613725）の非変換率は 1.8% で、SRX2613726 の mean_chh（0.234）は兄弟サンプル（0.170、0.184）より高い。
非変換率 n で観測値 m を補正すると（(m − n) / (1 − n)）、サブサンプルの核の重み付き値は CpG 0.445 → 0.389、CHG 0.352 → 0.286、CHH 0.241 → 0.164 となる。
補正後の CHH は兄弟サンプルの 0.191 と 0.217 に近く、差の大部分は変換不良で説明できる。

精子 3 件の高い CHH メチル化（mean_chh 0.28〜0.33）は、非変換率が 1.6〜2.3% にとどまるので、変換不良ではなく生物学的なシグナルと考えられる。
一方、Thallus と Apical Notch の CHH メチル化（mean_chh 0.016〜0.058）は非変換率（0.3〜2.2%）と同じ桁であり、CHH の値の大部分が非変換に由来する可能性がある。
サンプル間で CHH を比べるときは、非変換率を差し引くか併記する必要がある。

### 3.6 説明しきれていない残り

オルガネラを加えても、SRX2613744（62.4%）と SRX2613747（60.3%）を中心に、一部のサンプルでは 10〜40% のペアが一致ペアにならない。
これらのリードは directional の変換パターンを示し、G 含量がマップされたリードよりやや高い（0.21〜0.23 と 0.15〜0.16）。
rDNA 単位配列（AY342318）を参照に加えても率は変わらず（62.4% と 60.3% のまま）、16S パネルにも細菌の集中的なヒットはなかった。
組成からは、アセンブリから除かれた反復配列か、パネルにない混入源の可能性があるが、今回は特定していない。

## 4. サンプル別の判定

判定は、現在カタログに表示されている出力が使えるかどうかで付けた。

| 判定 | 件数 | サンプル | 理由 |
|---|---|---|---|
| FAIL | 3 | SRX2613745、SRX2613731 | R1/R2 の取り違えでメチル化値が無効 |
| | | SRX2613726 | 非変換率 9.2% |
| WARN | 10 | DRX162963、DRX162964 | 細菌混入で有効深度が低い |
| | | DRX162965 | 深度不足（CpG の 5 リード以上カバーが 1.5%） |
| | | SRX2613727、SRX2613729、SRX2613730、SRX2613732、SRX2613733、SRX2613739、SRX2613742 | 非変換率 2〜5%（CHH の解釈に注意） |
| PASS | 18 | 上記以外 | メチル化値は使える。マッピング率の低さは主にオルガネラによる（INFO） |

判定は 6 節の閾値案をそのまま当てはめたものである。
非変換率 2〜5% の WARN は、変換率 98% 以上という一般的な基準に合わせた。
2.1〜2.3% の 4 件（SRX2613733、SRX2613739、SRX2613742、SRX2613745）は境界上にあり、精子のように葉緑体リードの少ないサンプルでは、核の NUPT 由来のメチル化リードが推定値を押し上げている可能性もある。

精子 3 件以外の 28 件は、判定にかかわらず、3.1 節の NUPT と NUMT への誤配置による局所的な非メチル化の高カバレッジ領域を含む。
TSV では `cause` 列に `organelle_not_in_reference` として記録した。

TSV の主な列の意味は次のとおり。
`sub_` で始まる列と `pct_reads_`、`nonconv_` の列は先頭 25 万リード（ペア）のサブサンプルによる値で、それ以外はフルランの出力と DB の値である。

- **displayed_mapping_rate**：DB の mapping_rate（PE は一致ペア率、SE はリード率。多重ヒットを含む）。
- **unique_rate**、**read_level_mapped_rate**：フルランの abismal stats から求めた一意な一致ペア率（SE は一意リード率）と、片側 mate も含めたリード単位のマップ率。
- **sub_directional**、**sub_R**、**sub_P**、**sub_R_plus_organelle**：サブサンプルを現行の参照に directional、`-R`、`-P` でマップした率と、オルガネラ入りの参照に `-R` でマップした率。
- **pct_reads_chrC**、**pct_reads_chrM**、**pct_reads_phiX**：オルガネラ入りの参照で各配列に一意に配置されたリードの割合。
- **pct_reads_bacteria_panel**、**pct_reads_unmapped_all_refs**：競合マッピング（細菌 37 ゲノム入り）で細菌に配置されたリードと、どこにも配置されなかったリードの割合。
- **nonconv_chrC_CpG**、**nonconv_chrC_CHH**、**nonconv_lambda_CHH**：葉緑体（λ）上の重み付きメチル化率。非変換率の推定値。
- **sub_nuclear_wCpG**、**sub_nuclear_wCHG**、**sub_nuclear_wCHH**：競合マッピング後の核の重み付きメチル化率（R1/R2 が逆の 2 件では、正しい向きでの値になる）。
- **frac_cpg_covered**、**frac_cpg_cov_ge5**、**median_cpg_cov**：現行の CpG カバレッジ bigWig から求めた、ゲノム上の CpG（両鎖 20,705,802 個）のうち 1 リード以上、5 リード以上でカバーされた割合と、カバーされた CpG のカバレッジの中央値。
- **sex_inferred**：常染色体に対する chrV と chrU のカバレッジ比から推定した性別。

## 5. 推奨する対応

### 5.1 再解析のパラメータ

全 31 件を、次の 2 点を変えた設定で再解析することを勧める。
再解析しない場合でも、R1/R2 が逆の 2 件だけは必ず再解析する必要がある。
SRX2613726 は再解析しても変換不良は直らないので、非 CG コンテキストを比較から外すか、非変換率を差し引いて表示する。

1. abismal に `-R` を付ける。directional のデータでは結果がほぼ変わらず（29 件で差は最大 0.3 ポイント）、R1/R2 が逆のデータも救える。
2. 参照に葉緑体（AP025455.1）とミトコンドリア（MK202951.1）をデコイとして加える。メチル化の出力（bigWig、HMR など）は核の 10 本に限り、葉緑体上の CHH メチル化率を非変換率として stats に残す。

### 5.2 再解析しない、またはそれまでの間の UI 上の扱い

- SRX2613745 と SRX2613731：メチル化値とトラックを非表示にするか、「R1/R2 が逆で解析値が無効、再解析待ち」と明示する。

- 非変換率 2〜5% の 7 件：CHH の値に非変換率を併記する。
- マッピング率の欄名を、PE では「一致ペア率（concordant pairs、多重ヒットを含む）」とし、SE と並べて比較しないよう注記する。
- Known Limitations に「参照に葉緑体とミトコンドリアがないため、葉緑体の多い組織ではマッピング率が低く出て、核の葉緑体様配列に非メチル化の高カバレッジ領域が出る」と追記する。

## 6. ウェブサイト用の QC 指標と閾値の案

FAIL は「表示中のメチル化値が誤っている」場合に限り、深度や混入のように値は正しいが情報量が少ない場合は WARN にとどめる、という方針で閾値を置いた。

| 指標 | 計算方法 | PASS | WARN | FAIL |
|---|---|---|---|---|
| 変換の向き | R1 の C 含量と G 含量（fastp JSON）、abismal の一意ペアの誤り率 | R1 で C < G かつ誤り率 < 3% | 誤り率 3〜4% | R1 で C > G、または誤り率 ≥ 4% |
| 全コンテキスト高メチル化 | mean_cpg、mean_chg、mean_chh | | | 3 つとも ≥ 0.9 |
| 非変換率 | 葉緑体（または λ）上の CHH メチル化率 | < 2% | 2〜5% | ≥ 5% |
| Marchantia 由来でないリードの割合 | 1 −（核 + オルガネラ + スパイクインにマップされたリードの割合）。リード単位 | < 50% | ≥ 50% | |
| 深度 | 5 リード以上でカバーされる CpG の割合 | ≥ 5% | < 5% | |
| オルガネラ割合 | 葉緑体 + ミトコンドリアのリードの割合 | INFO のみ（組織に依存し、品質の指標ではない） | | |

最初の 2 項目と深度は、既存の fastp JSON、abismal stats、bigWig から求まるので、再解析を待たずにフラグ付けに使える。
この 2 項目だけで、R1/R2 が逆の 2 件を検出できる。
非変換率、Marchantia 由来でないリードの割合、オルガネラ割合は、5.1 節の変更で葉緑体を参照に加え、stats に列を追加してから求める。
現在の TSV の値は、今回のサブサンプルによる推定値である。

## 7. 検証した事項と推定にとどまる事項

検証した事項（サブサンプルでの再現と数値で確認）は次のとおり。

- 表示値の定義（PE は一致ペア率、多重ヒットを含む）。BAM レコード数との一致で確認。
- 葉緑体とミトコンドリアの欠落による率の低下（31 件すべてでモード別、参照別にマップ）。
- 葉緑体リードの核への誤配置と、それによる高カバレッジの非メチル化領域（SRX2613746 で領域を特定し、既存の bigWig で 9 サンプルを比較）。
- SRX2613745 と SRX2613731 の R1/R2 の逆転と、`-R` による回復。再マップ後のメチル化率が兄弟サンプルと整合することまで確認。
- DRX162963 と DRX162964 の、GC リッチで CpG 非メチル化の非 Marchantia リードの存在。
- SRX2613726 の変換不良（葉緑体とミトコンドリアの両方で 9% 前後）。λ を含む SRX1060228 で、葉緑体による非変換率の推定が λ と一致することも確認した。
- PBAT と non-directional の否定、retry-pe-fallback の未使用。

推定にとどまる事項は次のとおり。

- 混入源の分類（Rhodanobacteraceae 近縁）。パネルとの誤り率が 6% 前後あり、種や属は決まっていない。
- R1/R2 の逆転の原因（SRA 登録時のファイル取り違え）。同じプロジェクトの他の 22 件と同じキットであることからの推定。
- 3.6 節の残りの未マップリードの由来。
- 非変換率 2.1〜2.3% のサンプルの判定。葉緑体リードの少ないサンプルでは、NUPT 由来のメチル化リードが推定値を押し上げている可能性がある。
- NUPT と NUMT への誤配置が、領域単位の解析（HMR、PMD、hyperMR）や全体平均に与える影響の大きさ。カバレッジの割合と代表領域から推定した。
- フルランでの再解析後の値。数値はすべて先頭 25 万リードのサブサンプルによる（directional の率はフルランと 0.6 ポイント以内で一致）。
